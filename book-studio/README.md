# Book Studio

원고에서 인쇄용 PDF까지, 책 한 권을 만드는 출판 편집 프로그램입니다.
기능 단위(Phase)로 개발하며, 현재 **Phase 4 — 고급 편집 기능**의 일부까지 구현되어 있습니다(아래 ‘아직 없는 것’ 참고).

## 실행

```bash
npm install
npm run dev        # 브라우저에서 개발 실행
npm run desktop    # 빌드 후 데스크톱(Electron) 창으로 실행
npm test           # 조판·자동 조판·문서 모델·PDF 엔진 테스트

# 실제 브라우저로 원고 가져오기 → 자동 조판 → PDF 출력 흐름 확인 (Playwright, python-docx 필요)
python3 tests/e2e/make-fixtures.py tests/e2e/out
npm run build && npx vite preview --port 4173 &
npm run e2e
```

## 지금 되는 것

### Phase 1 — 핵심 편집 엔진
- 새 책 만들기: 책 정보 → 판형(신국판·국판·46판·A5·B5·46배판·A4·국배판·사용자 지정) → 양면/단면, 좌철/우철, 추천 여백 → 디자인 템플릿
- 자유 배치 쪽: 글 상자와 이미지(JPG·PNG·WEBP)를 놓고 옮기고 크기를 바꿈, 글 넘침 감지, 이미지 유효 해상도 표시
- 한글 조판: 글자/낱말 단위 줄바꿈, 문장부호 금칙 처리, 양쪽 정렬
- 페이지 추가·삭제·복제·순서 변경, 한 쪽/펼침면 보기, 실행 취소, 자동 저장, 프로젝트 파일(.bookstudio)
- 사용자 폰트(TTF/OTF) 추가 — 임베딩이 금지된 폰트는 거부
- 일반 PDF 출력: 완성 크기 그대로, 쓰인 글자만 폰트 임베딩

### Phase 2 — 출판 편집 기능
- **원고 가져오기**: TXT(UTF-8·UTF-16·EUC-KR), Word(DOCX), 한글(HWPX, HWP 5.0). 가져오기 전에 읽은 구조(장·절·본문·이미지 수)와 잃는 서식을 미리 보여 줌
- **자동 조판**: 원고가 본문 쪽에 흘러 들어가고, 분량에 맞춰 쪽이 자동으로 늘고 줄어듦. 글이나 스타일이 바뀐 문단만 다시 조판
  - 장은 새 쪽에서 시작, 제목이 쪽 맨 아래에 홀로 남지 않음, 쪽을 넘는 문단은 양쪽에 두 줄 이상 유지
  - 사용자가 지정한 ‘새 쪽에서 시작’은 그대로 지킴
- **원고 보기**: 문단 단위로 글을 쓰고 고침(Enter로 나누기, Backspace로 합치기), 문단 종류 지정, 본문 사이 이미지
- **문단 스타일**: 장 제목·절 제목·본문·인용문. 스타일을 고치면 책 전체에 반영
- **쪽 번호**: 위치, 아라비아/로마 숫자, 시작 쪽과 시작 번호
- **머리말(공통 요소)**: 좌우 쪽에 책 제목·장 제목·저자, 쪽별 숨김, 장 시작 쪽 자동 제외
- **자동 목차**: 장·절 제목과 쪽 번호, 점선 리더. 쪽이 바뀌면 번호도 자동 갱신
- **내지 템플릿**: 에세이형·소설형·시집형·실용서형(수정 가능한 시작점)

### Phase 3 — 표지 및 인쇄 기능
- **표지 편집**: 뒤표지·책등·앞표지(와 날개)를 하나로 이어 편집. 표지 템플릿 4종, 배경색, 글·이미지·도형(사각형), 90° 단위 회전
- **책등 자동 계산**: 내지 장수 × 종이 두께(종이 프리셋은 참고값, 직접 입력 가능). 인쇄소가 알려 준 책등 너비를 직접 넣을 수 있음. 쪽수가 바뀌면 표지 크기가 자동으로 바뀌고 앞·뒤표지 요소는 제자리를 지킴
- **도련·재단선·안전 영역**: 표지와 내지에서 도련 영역 보기, 접는 선·안전 영역 안내선
- **PDF 내보내기**: 화면용 / 검수용(도련·재단선, RGB) / 인쇄용(도련, 재단선, 글자·도형 CMYK, 검정은 먹 1도). 내지와 표지를 각각의 파일로, 내지는 낱장 순서로 출력. TrimBox·BleedBox 기록
- **PDF/X-4**: 인쇄소가 지정한 CMYK 출력 프로파일(ICC)을 불러오면 출력 인텐트·버전 표기·XMP·문서 ID를 넣고, RGB 이미지에는 sRGB 색 공간을 지정
- **인쇄 사전 검사**: 글 넘침, 이미지 해상도, 없는 이미지·폰트, 도련 누락, 안전 영역 침범, 빈 쪽, 제본에 맞지 않는 쪽수, 책등 조건 등을 오류·경고·정보로 나누어 보여 주고, 항목을 누르면 해당 위치로 이동

### 인쇄 출력의 한계 — 인쇄소에 넘기기 전에 꼭 확인하세요
- **PDF/X-4 출력은 공인 검증 도구(Acrobat Preflight 등)나 실제 인쇄소 출력으로 확인되지 않았습니다.** 규격이 요구하는 항목을 넣었지만 준수 여부는 인쇄소의 사전 검사로 확인해야 합니다.
- 이미지는 CMYK로 변환하지 않고 sRGB로 넣습니다(인쇄소 RIP가 변환). 색을 직접 관리하려면 이미지를 미리 CMYK로 바꿔 넣는 기능이 필요한데 아직 없습니다.
- CMYK 출력 프로파일은 배포 가능한 것이 없어 포함하지 않았습니다. 인쇄소에서 받은 ICC 파일을 불러와야 PDF/X-4를 쓸 수 있습니다.
- 글자·도형 색은 단순 계산식으로 CMYK로 바꿉니다(ICC 기반 변환 아님). 별색, 오버프린트 설정, PDF/X-1a, 펼침면·대지 배치(터잡기) 출력은 없습니다.
- 양장제본, 바코드 생성, 세로쓰기 책등 글자(지금은 90° 회전), 선·일러스트 도형은 없습니다.

### Phase 4 — 고급 편집 기능 (일부)
- **문단 안 글자 서식**: `**굵게**`(Ctrl+B), `*기울임*`(Ctrl+I). 본문 흐름과 글 상자 모두에서 동작. 기울임은 글자를 12° 눕혀 표현(별도 이탤릭 글꼴 아님)
- **각주**: `[^각주 내용]`을 넣은 자리에 번호가 붙고, 내용은 번호가 있는 쪽 아래에 구분선과 함께 놓임. 번호는 쪽마다 1부터
- **기준선 격자**: 본문 문단의 첫 줄을 본문 줄 높이의 배수 자리에 맞춤, 격자 선 표시
- **장별 쪽 번호**: 장이 시작할 때마다 번호 다시 시작
- **공통 요소(마스터)**: ‘공통’ 보기에서 놓은 글·이미지·도형이 모든 쪽 아래에 깔림(공통 요소를 숨긴 쪽 제외)
- **레이어**: 요소 목록에서 선택, 숨김(화면·PDF 제외), 잠금, 한 단계씩 순서 변경
- **3D 책 미리보기**: 표지와 책 두께를 입체로 돌려 봄
- **내 템플릿**: 지금의 문단 스타일·쪽 번호·머리말 설정을 이름 붙여 저장하고 다른 책에 적용
- **인쇄소별 설정**: 도련·제본·출력 프로파일·종이를 인쇄소 이름으로 저장하고 적용
- Word(DOCX)의 굵게·기울임·각주를 가져옴

### 가져오기의 한계
- Word의 굵게·기울임·각주는 가져오지만(각주 가져오기는 실제 Word 파일로 미확인), 밑줄·첨자, 표 모양은 가져오지 않습니다(표는 줄글로). HWP·HWPX는 글자 서식과 각주를 가져오지 않습니다.
- HWP는 글 내용만 읽고 문단 스타일은 읽지 않습니다. HWPX는 직접 만든 시험 파일로만 확인했습니다(한글에서 저장한 실제 파일로는 미확인).
- DOC, RTF는 지원하지 않습니다(DOCX로 저장해서 가져오도록 안내).

## 아직 없는 것

화면에 없는 기능은 구현되지 않은 것입니다.

- 미주, 표, 밑줄·취소선, 첫 글자 장식, 탭, 세로쓰기, 글 상자 연결, 책 전체 연속 각주 번호(지금은 쪽마다 1부터)
- 내 템플릿과 인쇄소별 설정은 이 기기에만 저장됩니다(프로젝트 파일에는 적용된 결과만 들어감). 공통 요소는 좌우 쪽에 따라 뒤집히지 않고, 사전 검사 대상이 아닙니다.
- 3D 미리보기의 쪽 넘김, 요소 자유 각도 회전, 선·원 도형
- Phase 5: Windows 설치 프로그램, 업데이트, 실제 인쇄소 출력 검증

## 구조

```
src/model/    문서 모델(JSON, mm·pt 물리 단위), 판형 프리셋, 표지 좌표와 책등 계산(cover)
src/engine/   폰트 레지스트리, 줄 조판(layout), 자동 조판·목차·쪽 번호(flow), 원고 가져오기(import), PDF 출력(화면용·인쇄용·PDF/X-4), 인쇄 사전 검사(preflight), 폰트 서브셋(HarfBuzz)
src/store/    편집 상태·실행 취소 기록·자동 저장(IndexedDB)
src/ui/       홈, 원고 가져오기, 새 책 마법사, 편집 화면(캔버스·원고 보기·패널)
electron/     데스크톱 실행 껍데기
```

편집 화면(SVG)과 PDF는 같은 문서 모델과 같은 조판 결과(`engine/layout.ts`)를 그립니다.
글자 폭은 폰트 파일에서 직접 읽으므로 화면과 PDF의 줄바꿈·위치가 일치합니다(화면 캡처 방식이 아닙니다).
