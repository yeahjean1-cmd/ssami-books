# Book Studio

원고에서 인쇄용 PDF까지, 책 한 권을 만드는 출판 편집 프로그램입니다.
기능 단위(Phase)로 개발하며, 현재 **Phase 1 — 핵심 편집 엔진**까지 구현되어 있습니다.

## 실행

```bash
npm install
npm run dev        # 브라우저에서 개발 실행
npm run desktop    # 빌드 후 데스크톱(Electron) 창으로 실행
npm test           # 조판·문서 모델·PDF 엔진 테스트
npm run build && npx vite preview --port 4173 &   # 그다음
npm run e2e        # 실제 브라우저로 책 만들기 → 편집 → PDF 출력 흐름 확인 (Playwright 필요)
```

## 지금 되는 것 (Phase 1)

- 새 책 만들기: 책 정보 → 판형(신국판·국판·46판·A5·B5·46배판·A4·국배판·사용자 지정, 세로/가로) → 양면/단면, 좌철/우철, 추천 여백
- 페이지 추가·삭제·복제·순서 변경(버튼, 끌어 놓기), 한 쪽/펼침면 보기, 확대·축소
- 글 상자: 서체·크기·굵기·행간·자간·색상·정렬(양쪽 정렬 포함)·들여쓰기·문단 간격·줄바꿈 방식, 글 넘침 감지
- 한글 조판: 글자 단위/낱말 단위 줄바꿈, 문장부호 금칙 처리, 영문 낱말 보존
- 이미지(JPG·PNG·WEBP): 채우기/맞추기/늘이기, 불투명도, 실제 인쇄 크기 기준 유효 해상도 표시와 저해상도 경고
- 여백 설정과 안내선(좌우 쪽의 안쪽·바깥쪽 여백 자동 반전)
- 실행 취소/다시 실행, 자동 저장(기기 내 저장), 프로젝트 파일(.bookstudio) 내보내기·열기
- 사용자 폰트(TTF/OTF) 추가 — 임베딩이 금지된 폰트는 거부
- 일반 PDF 출력: 완성 크기 그대로, 쓰인 글자만 폰트 임베딩

## 아직 없는 것

화면에 없는 기능은 구현되지 않은 것입니다. 다음 순서로 개발합니다.

- Phase 2: DOCX·TXT·HWP(X) 원고 가져오기, 자동 조판(글 상자 연결·쪽 자동 생성), 쪽 번호, 자동 목차, 마스터 페이지, 문단 스타일, 템플릿
- Phase 3: 표지(앞·등·뒤)와 책등 계산, 도련·재단선, CMYK·PDF/X 인쇄용 PDF, 인쇄 사전 검사
- Phase 4: 각주·기준선 격자·세로쓰기 등 고급 조판, 레이어, 도형, 요소 회전, 3D 미리보기
- Phase 5: Windows 설치 프로그램, 업데이트, 실제 인쇄소 출력 검증

현재 PDF는 RGB 색상의 화면용·검수용입니다. 인쇄소 제출용(도련·재단선·CMYK·PDF/X)은 Phase 3에서 다룹니다.

## 구조

```
src/model/    문서 모델(JSON, mm·pt 물리 단위), 판형 프리셋
src/engine/   폰트 레지스트리, 조판(layout), PDF 출력, 폰트 서브셋(HarfBuzz)
src/store/    편집 상태·실행 취소 기록·자동 저장(IndexedDB)
src/ui/       홈, 새 책 마법사, 편집 화면(캔버스·패널)
electron/     데스크톱 실행 껍데기
```

편집 화면(SVG)과 PDF는 같은 문서 모델과 같은 조판 결과(`engine/layout.ts`)를 그립니다.
글자 폭은 폰트 파일에서 직접 읽으므로 화면과 PDF의 줄바꿈·위치가 일치합니다(화면 캡처 방식이 아닙니다).
